# 🚀 NamePixel AI

A smart and creative **Name to Image Generator Web App** that transforms any name into a visual art using letter-based images (a-z).

---
<img src="img/demo.png" alt="NamePixel AI Demo" width="600">

## ✨ Features

- 🔤 Convert name into image-based letters (a-z.jpg)
- 🌐 URL auto generation support (`?name=rony`)
- 📸 Download generated name as image (PNG)
- 📱 QR Code generator for sharing links
- ⚠️ Input validation with popup alerts
- 💡 Clean modern UI design
- ⚡ Lightweight (pure HTML, CSS, JS)
